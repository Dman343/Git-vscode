# VSCode Config (Android)

Android Jetpack Compose rewrite of the `Dman343/Git-vscode` `.vscode/settings.json` configuration repository.

## Features

- **`.NET Acquisition Extension` Settings Controls**: Interactive Material 3 toggles for:
  - `dotnetAcquisitionExtension.enablePreviewFeatures` (default: `true`)
  - `dotnetAcquisitionExtension.highVerbosity` (default: `true`)
  - `dotnetAcquisitionExtension.suppressOutput` (default: `false`)
- **Live `settings.json` Inspector & Raw Editor**: Real-time 4-space formatted JSON view with syntax highlighting, line numbers, clipboard copy, and validated raw JSON editing.
- **Repo Default Sync & Reset**: Tracks modifications against the imported `.vscode/settings.json` baseline with per-key or full reset actions.
- **Adaptive Layout & Theme**: Responsive single-pane (`Compact`) and side-by-side two-pane (`Medium` / `Expanded`) layouts with dark and light themes.
